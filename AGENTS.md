# Project Information

1. Technical Deliverables

Open Source Codebase: A public GitHub repository link containing your clean, readable code.
Aevum Blockchain Integration: Evidence that your application utilizes the QDay infrastructure (such as smart contracts, ERC-8004, QDay dapps).
Live Deployment: A functional demo, prototype interface, or access to the packaged Docker image executing the application logic.

2. Documentation & Presentation

Video Pitch & Demo: Top 5 projects will be invited to a 3 to 5-minute video call presentation demonstrating the live, operational workflow of the application.
Project Documentation: A brief overview explaining the problem your application solves, its system architecture, the core workflows, and a list of technologies used.

3. No malicious code

No malicious code and no attempts to attack the platform or other participants.
